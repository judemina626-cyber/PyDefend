PYDEFEND RENDER DEPLOYMENT

Build command:
pip install -r requirements.txt

Start command:
gunicorn --bind 0.0.0.0:$PORT --workers 1 --timeout 120 --access-logfile - --error-logfile - app:app

Health check:
/api/health

No environment variable is required manually; PYDEFEND_SECRET can be generated by Render.

For GitHub upload, upload the CONTENTS of this folder so app.py is at repository root.
